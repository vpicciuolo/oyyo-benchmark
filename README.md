# OYYO Benchmark

Public, reproducible evaluation framework for OYYO model, runtime, hardware, business, language, multimodal, agent, and efficiency benchmarking.

Primary project domain: https://oyyo.one

## Status

Foundation release: `0.1.0`

The benchmark is intentionally developed before OYYO commits to a foundation model family. Candidate models are compared on quality, task success, reliability, latency, memory use, hardware compatibility, and reproducibility.
